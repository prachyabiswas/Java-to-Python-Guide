# From Java to Python

## My Journey

I started out learning **Java** — it's where I first got comfortable with core programming concepts: static typing, classes, loops, OOP structure. It gave me a solid, disciplined foundation in how programs are built.

But as my focus shifted toward **data science, machine learning, and AI** — the direction I wanted my career to go — Python became unavoidable. Nearly every tool in that space (NumPy, pandas, scikit-learn, PyTorch, TensorFlow) is Python-first, and the language itself is simply faster to prototype in. So I made the switch deliberately, not by abandoning Java, but by **mapping what I already knew onto Python's syntax and idioms** — learning *through* the language I already understood, instead of starting from zero.

That's exactly what this repo is: the reference I built for myself during that transition, and the guide I wish I'd had on day one.

## What's Inside

**[`java-to-python.md`](./java-to-python.md)** — a side-by-side Java ↔ Python reference covering:

- Variables, data types, and type checking
- Printing, concatenation, and arithmetic
- Strings (indexing, slicing, length)
- User input
- Conditional statements (`if`/`elif`/`else`, `and`/`or`, nested `if`, `pass`)
- Python's built-in data structures (`list`, `tuple`, `set`, `dict`) — and what's different from Java arrays
- Loops (`while`, `for`, `break`, `continue`, nested loops)
- Functions (and why Python's default arguments replace Java's method overloading)
- NumPy — the closest thing Python has to Java's native arrays, and why it's worth learning on top of plain lists

Every topic is shown as **working code in both languages, with actual output**, plus notes on the gotchas that trip up anyone making this same switch (e.g., Python's `input()` always returns a string, `+` can't silently mix `str` and `int`, negative indexing, etc.).

## Who This Is For

Anyone who already thinks in Java — or any statically typed, curly-brace language — and wants to get productive in Python quickly by relating new syntax to concepts they already know, rather than learning Python as if from scratch.
